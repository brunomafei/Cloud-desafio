# Cloud-desafio

1 - A camada 2 cuida da comunicação na mesma rede local usando endereços fi­sicos como o MAC e protocolos tipo Ethernet. ja a camada 3 faz o roteamento entre redes diferentes, usando endereços IP para definir a melhor rota dos pacotes de dados.

2 - O Windows e pago e tem otima compatibilidade, mas te prende ao ecossistema da Microsoft. O Ubuntu ja gratuito e mais flexi­vel, mas exige mais conhecimento tecnico e as vezes da problema de compatibilidade com alguns aplicativos.

3 - Projetos Open Source tem codigo livre para qualquer um acessar e modificar. As empresas usam isso para cortar custos, mas o desafio e que elas assumem toda a responsabilidade pela manutenção.
